## Project Overview
**Theme:** Restaurant & Online Food Ordering  
**Description:** A responsive multi-page restaurant website for Bite Club featuring menu browsing, deals, online ordering with interactive confirmation alerts, and branch contact details.

## Pages Included
- `index.html` — Home page featuring deals, main items, and restaurant address
- `menu.html` — Full Menu page
- `order.html` — Order Online page with JavaScript confirmation alert
- `contact.html` — Contact Us page with branch details and opening hours

## AI Tools Used
- Google Gemini (used for feature development, Git branching/merging workflow, and GitHub Pages deployment)
